# Cosmos Hit Effects

Client-side Fabric mod for Minecraft 1.21.11.

## Effects

- Player hurt flashes are replaced with a pulsing violet, magenta, and cyan cosmos tint.
- Player hits emit a short nebula-colored burst.
- Critical hits emit a radial starburst using end-rod stars.

## Build

Use Java 21 and run `gradle build` from this folder, or import the folder as a Gradle project in IntelliJ IDEA. The finished mod is written to `build/libs/`.

This is a client-only visual mod; it does not change damage, combat timing, or server gameplay.
